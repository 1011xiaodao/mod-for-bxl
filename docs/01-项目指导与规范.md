## 1. 硬约束（全项目通用）

- 基线 **MC 1.21.1 + NeoForge 21.1.x + Java 25** 不变；ModDevGradle 模板
- 构建资源统一：**Gradle 9.1 / MDG 2.0.146 / JDK 25 / 统一仓库镜像模板**（详见 `参考/00-构建资源统一规范.md`）；不得自行引入新版本
- `org.gradle.java.home` 必须填**纯 ASCII 路径**（含中文路径 Gradle 拒绝启动 daemon；相对路径不可靠，已废止）
- Git 提交中文并打里程碑 tag（如 `M6.1`）
- 汇报面向编程新手（项目主），全部中文，验收步骤傻瓜式
- 多线程纪律（全项目强制，2026-09-06 签发）：
  1. 重计算后台化：批量/重计算任务投递命名守护线程池，完成后经主线程队列回投
  2. 分帧与降频：算不完的任务按 tick 预算分片（每 tick ≤0.5ms）或降频（每 N tick 一次）——殖民地经济 60s tick 即此模式
  3. IO 全异步：文件/网络/下载/落盘一律离开主线程
  4. 跨线程数据纪律：只传不可变快照或并发容器；禁止跨线程加锁游戏对象；共享状态写入必须在主线程完成
  5. 验收门槛：里程碑回报须附主线程耗时证据（Spark 或等效）；新增 tick 逻辑超预算即打回
  - 本项目专项：经济 tick（60s）之外，市场撮合、领地扫描、过期清理全部分片/后台化
