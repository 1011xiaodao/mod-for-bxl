# 《数值速调手册》——殖民地经营（M6.1）

> 面向项目主：改 JSON/配置 → 不用重启服务器，游戏内 `/reload` 即生效（建筑定义）。
> 全部数值参数化，禁止改代码硬编码。

## 1. 建筑逐级数值（datapack JSON）

位置：`src/main/resources/data/pioneer_colony/pioneer_colony/buildings/*.json`
（正式整合包里也可放任意 datapack 的同路径目录，同名 id 覆盖/异名追加——附属模组如巨构拓展即用此机制）

| 字段 | 说明 |
|---|---|
| `max_tier` | 最高等级 |
| `build_seconds_per_tier` | 各级施工时长（秒） |
| `cost_per_tier` | 各级建造材料 `[{"item":"minecraft:iron_ingot","count":8}]` |
| `input_per_min` | 每分钟原料消耗（缺料自动降效率） |
| `output_item` | 产出物品 id（不填则该建筑无产出） |
| `output_per_min_per_tier` | 各级每分钟产出量（生产公式见下） |
| `worker_slots_per_tier` | 各级岗位数（市民自动上岗） |
| `profession` | 职业名（岗位表现用） |
| `maintenance_per_hour` | 每小时维护材料（断供 → 效率减半） |
| `resident_slots_per_tier` | 各级床位数（人口上限） |
| `buffer_slots_per_tier` / `buffer_per_type_capacity_per_tier` | 各级缓冲扩容（仓库类） |

- **数组长度规则**：长度 = `max_tier`；写长度 1 表示全等级共用一个值；两者之外视为非法条目（跳过并记日志）。
- **生产公式**：`实际产出 = 产出/分 × 满足输入比 × 岗位填充率 × 全局加成 × 幸福度乘数`；
  消耗与维护同比例（幸福度不放大消耗，只提升单位投入产出比）。
- 改完 `/reload`，聊天栏/日志会显示「建筑定义加载完成：N 栋」。

## 2. 全局参数（config，`run/config/pioneer_colony-server.toml`）

改 config 需重启服务器（NeoForge 服务端 config 不热载）。

| 项 | 默认 | 说明 |
|---|---|---|
| economy.tickSeconds | 60 | 经济 tick 周期（秒） |
| economy.offlineCatchupCapHours | 24 | 离线补算上限（小时） |
| economy.startingCredits | 500 | 创建殖民地启动资金 |
| economy.initialPopulation | 5 | 初始人口 |
| economy.coloniesPerPlayer | 1 | 每玩家殖民地上限 |
| economy.bufferBaseTypes / bufferPerTypeCapacity | 5 / 256 | 缓冲基础容量（种类/单类） |
| economy.foodPointsPerCitizenPerDay | 12.0 | 每市民每游戏日食物点需求 |
| economy.foodGlobalMultiplier | 1.0 | 食物点全局倍率 |
| economy.foodValueOverrides | 空 | 个别物品食物点覆盖 `minecraft:bread=6.0` |
| economy.popGrowthIntervalGameDays | 1 | 人口自然增长间隔（游戏日） |
| happiness.base / heatingWeight / foodWeight / housingWeight | 25 / 35 / 25 / 15 | 幸福度公式权重（M6.6 定稿） |
| territory.maxChunks | 256 | 领地上限（区块） |
| maintenance.halfEfficiencyFactor | 0.5 | 维护断供效率倍率 |
| debug.logEconomyTick | false | 每次经济 tick 日志输出耗时（验收证据开关） |

## 3. 食物点速查（自动读取，零配置）

食物点 = 物品实际恢复的饱和度值（1.21.1）：面包 6.0；非食物为 0（小麦 0——需食堂烹饪，M6.6）。
个别物品想改，用 `foodValueOverrides`。
