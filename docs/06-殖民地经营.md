> 本文档自包含，可单独交给一个 Agent 实施，无需其他文档。
> **架构定性**：策略经营式**抽象模拟**模组——基地运营是纯数据公式运算，AI 实体只在玩家可见范围内作为表现层存在、以及袭击战斗期间短暂出现。**本模组取代 MineColonies**（后者从整合包移除，不再使用）。

## 1. 开发方向与目标

玩家扮演殖民星球的总督：**建筑提供产出与消耗（公式运算），研究通道衔接整包科技总线（见 §5），袭击事件提供战斗张力**。基地 7×24 永续运营，但服务器只为它付出"每分钟一次公式"的代价。

**性能模型（本模组的立身之本，所有设计决策服从它）**：
- 平时：零实体 AI。经济 = 每 60 秒一次纯数据公式运算，与区块加载完全解耦（玩家离线照常运算；研究推进由 [研究台] 同频处理）
- 模拟：市民实体与原版村民同机制——常驻存档、跟随服务器**模拟距离** tick；模拟距离拉大即可全城居民模拟，范围外由原版机制冻结、零运算
- 袭击：唯一真实体战斗，事件驱动，且仅在附近有玩家时才开打

**范围（本期）**：殖民地数据模型、**领地系统（区块购买 + 基础保护）**、经济模拟、建筑系统（GUI/施工/食物生产链）、研究通道（集成 [研究台]）、扩展资源框架、**经济与商贸（金库/市场/贸易）**、袭击事件、市民日程模拟（跟随模拟距离）、**幸福度指数**（殖民地级标量：供暖/食物/住房三因子 → 人口增速乘数；市民个体心情模拟仍不在范围）。
**非范围**：领地区块加载（未来独立功能；买地不加载区块，经济靠公式离线运算）、**总部搬迁**（v2 备选，本期总部原地修复重建）、政策系统（见 §14 v2 设计储备）、玩家 vs 玩家殖民地战争、市民个体生活模拟（社交/心情等高级需求）、玩家间拍卖行/玩家商店（属服务器插件领域，不重复造轮子）。

## 2. 架构：三层模型

| 层 | 内容 | 成本 |
|---|---|---|
| **数据模拟层** | 殖民地=存档数据（领地/建筑/人口/资源缓冲/研究/威胁值/幸福度）；每 60s 经济 tick 跑公式；离线按时长补算（设上限，默认补算上限 24h） | ≈0 |
| **市民模拟层** | 市民实体与原版村民同机制：常驻存档于所在区块，**跟随服务器模拟距离（simulation-distance）**决定是否 tick——玩家把模拟距离拉大，整座城市的居民都会模拟；范围内按日程通勤（家→工坊→食堂→家），带寻路与岗位动作 | 中（与原版村庄相当，规模可配） |
| **交互层** | 建筑方块 GUI：查看产出/调配岗位/收取货物；市政厅 GUI：总览/研究/威胁/领地/**城市管理** | 常规 GUI |

数据与实体的边界：生产数字永远由数据层公式决定，市民实体负责通勤、就餐与岗位作业的表现；玩家从建筑 GUI 收货，不从实体身上拿。玩家离开/区块卸载 → 实体随区块存档冻结（原版机制），日程进度与位置随之保存，生产不受任何影响。

## 3. 经济模拟（核心系统）

### 3.1 数据模型

殖民地（每玩家 1 个，可配）：UUID、名称、总部坐标（维度+xz）、**领地区块集合**、建筑列表、人口、资源缓冲（Map<ItemKey, long>）、**伪空间暂存区**（仓库意外失效时保全物资）、**金库（信用点余额）**、**市场挂单列表**、研究进度、威胁值、**幸福度指数**、**总部状态**（正常/受损/停摆待修复）、最近 tick 时间戳。

### 3.2 建筑（datapack JSON 定义）

`data/<datapack>/pioneer_colony/buildings/*.json`：

```json
{
  "id": "smelter",
  "name": "冶炼舱",
  "max_tier": 5,
  "build_seconds_per_tier": [600, 900, 1200, 1800, 2400],
  "cost_per_tier":  [ {"item":"pioneer_colony:alloy_plate","count":8} ],
  "input_per_min":  [ {"item":"minecraft:iron_ore","count":4} ],
  "output_per_min_per_tier": [6, 9, 13, 18, 24],
  "worker_slots_per_tier": [1, 1, 2, 2, 3],
  "profession": "technician",
  "maintenance_per_hour": [ {"item":"pioneer_colony:alloy_plate","count":1} ],
  "population_provided": 0,
  "research_required": "colony/metallurgy_1"
}
```

- 逐级数值（产出/岗位数/施工时长）用**按等级索引的数组**表达，改一个数字即调一级，禁止硬编码
- 产出公式：`实际产出 = 产出/分 × min(1, 满足输入比) × 岗位填充率 × 全局加成 × 幸福度乘数`；缺输入自动降效率并在 GUI 告示
- 资源缓冲入不敷出时，按优先级表扣减（可配：食物 > 维护材料 > 生产输入）；**维护断供 → 该建筑效率减半**
- **建筑形态（定稿）**：**多方块结构 + 逻辑核心方块**（参照 MineColonies 的蓝图模式）——玩家放置的"建筑地基"即逻辑核心（BlockEntity 存数据），施工完成时整栋结构按当前等级蓝图**一次放置**，有内部空间供市民作业/就餐/起居；升级=按更高等级蓝图替换结构
- **结构蓝图 v1 由代码程序化生成占位**（殖民舱风格框架+功能方块），项目主后续用结构方块/蓝图工具替换正式设计，不阻塞开发
- **禁挖保护（定稿）**：建筑结构方块对玩家不可挖掘（创造/OP 除外）；破坏只可能来自袭击"受损"系统（状态标记，不逐块破坏）
- **拆除与回收（定稿）**：建筑 GUI「拆除」按钮 → 倒计时 → 返还材料 50%（可配）、建设费不退；拆除后地块可再建
- 人口与就餐：住宅类建筑提供人口上限（`resident_slots`）；**食堂**类建筑是市民就餐行程的目的地；人口是**数据**（岗位填充率来自人口分配）。初始人口由总部自带（默认 5，可配）；食物盈余且有空床位时每游戏日 +1（增速再乘幸福度乘数，见 §8.3），上限即床位数；**星际移民事件（定稿，参照放逐之城 nomads）**：总部 ≥2 级、有空床位且食物点充足时，每 N 游戏日判定一次，概率抵达一批移民（+1~3 人口）——自然增长之外的主动扩张途径，总部 GUI 可开关
- **食物生产链（定稿）**：农场产出**原料**（小麦等作物入缓冲）→ **食堂兼营烹饪**（v1 定稿：内置烹饪配方 `cooking/*.json`，如 小麦×4 → 面包）→ 熟食才有食物点（=该物品的饱和度值，自动读取、零配置，另配全局倍率+个别物品覆盖表）；市民就餐消耗食物点。磨坊/工坊类深度加工列 v2（§14）
- **食物储备指标**：建筑/总部 GUI 显示"食物可维持 N 天"（食物点存量÷日消耗），低于 3 天红字告警
- **仓库与缓冲容量**：总部自带小缓冲（默认 5 种物品 × 各 256 个，可配）；「殖民地仓库」建筑扩容（每级增加物品种类数与单类容量）。仓库不可用（未建/被毁）期间，施工材料改从玩家背包扣
- **伪空间保障**：仓库因恶意破坏/意外（卡块、区块异常等）失效时，缓冲物资整体转入殖民地数据的"伪空间暂存区"（纯数据，容量无上限），仓库重建后**自动全额返还**——玩家永不因仓库意外而真正丢货
- **首批建筑（10 栋**，全 JSON 定义，项目主可增删）：总部（市政厅）、殖民地仓库、住宅、食堂（兼烹饪）、农场、冶炼舱、守卫哨、贸易站、**研究院**（科研员岗位，驱动 colony 通道加速）、**锅炉房**（供暖产热，见 §8.3）
- 施工：放置"建筑地基"方块 → GUI 选类型 → 扣料（材料 + **一次性信用点建设费**）→ 倒计时（围挡表现，见 §8.2）→ 整栋结构一次成型。**材料来源**：优先从殖民地仓库扣，仓库不可用时从玩家背包扣。升级同理。建筑只能放在自有领地区块内（见 §4）
- **附属扩展**：附属模组可用同一格式追加建筑定义（如 [巨构拓展] 的太空指挥部/发射台/太空电梯），本模组建筑系统原样加载，无需本模组改代码

### 3.3 经济 tick

- 每 60s 对每个殖民地跑一轮：输入扣减→产出入缓冲→维护消耗（断维护效率减半）→食堂烹饪→人口食物消耗（断粮降效率并警告，**持续断粮每游戏日人口 -1**，数值可配）
- 离线补算：`结算量 = min(离线时长, 补算上限) ÷ 60 × 公式`，一次性入账；**上线时聊天栏推送一条离线汇总**（离线时长/产出/消耗/成交/事件），一眼看清家里发生了什么
- 总部状态：总部因袭击耐久打空或被主动拆除 → 殖民地进入"停摆"（公式暂停、数据保留），总部核心方块**原地**进入"待修复"状态，GUI 支付材料+费用、倒计时后原地恢复满效；**不做搬迁机制**（v2 备选，见 §14）

### 3.4 扩展资源框架（附属资源接入位）

- 本体 v1 的殖民地运行成本只有物品消耗（食物/维护），**没有电力**——电力在整合包里是科技模组机器级的 FE 能量，不是殖民地层面概念；殖民级资源由附属经"扩展资源框架"接入：
  - [纳米工厂]：**算力**（token/s 实时量表——算力枢纽产出、工厂与玩家算力网络消耗）
  - [巨构拓展] v2：**能量**（戴森云产出 → 殖民地能量 Gauge）
- 框架定义 Gauge 通用行为：容量、实时产出/消耗、**短缺惩罚曲线**（不足时相关建筑效率按可配曲线衰减）、断供恢复、审计接入
- **热能为本模组自注册**（锅炉房 + 算力枢纽余热回收 → 住宅供暖，见 §8.3），是框架的首个内置用户——框架先行实装、热能即验收用例
- 本体功能不依赖任何扩展资源；框架本身属于本体（M6.9 前实装）

## 4. 领地系统（区块购买 + 基础保护）

- **购买区块作为领地**：创建殖民地时免费获得总部周围 **3×3 共 9 个区块**；之后花费信用点购买区块——**买到哪，建到哪**（取代"总部半径"限制）。新购区块须与已有领地相邻（防天女散花式圈地；是否允许飞地可配）
- **定价**：越买越贵，`第 N 块价格 = 基础价 × N`（曲线与基础价全参数化，数值待项目主调）；购买入口在总部 GUI「领地」页签（区块网格图，点击购买，**30 秒购地冷却**防手滑连买）
- **领地上限**：默认 256 块（可配），防一人圈全服；**退地**：区块内无建筑时可放弃，退还购地费 50%（可配）
- **他人领地边界在领地地图上可见**（边界线显示，防误入）
- **建筑放置门槛**：建筑地基只能放在自有领地区块内，否则禁止放置并提示
- **维度限定**：殖民地仅限主世界——下界/末地禁止放置总部与建筑地基，提示"环境不适合殖民"
- **基础保护（对标市面领地模组的功能集）**，非本殖民地成员在领地内：
  - 禁止破坏/放置方块，禁止点燃、爆炸破坏、活塞推拉破坏
  - 禁止打开殖民地建筑/总部 GUI，禁止伤害/交互市民实体
  - 领地内怪物生成照常（袭击不受领地保护影响）；玩家间 PVP 规则沿用服务器设定
- **信任名单（两档权限）**：**访客**（领地内通行 + 贸易站交互）、**可信**（+ 开建筑 GUI 收货）；购地/拆建筑/签协定/解散永远只有总督本人。总部 GUI「领地」页签管理
- **实现形态**：领地保护**集成在本模组内**，玩家不需要另装领地模组；整合包层面保证只装一套保护，避免与其他保护模组冲突
- **明确不做**：领地区块加载（见 §1 非范围）

## 5. 研究通道（与 [研究台] 的集成）

> 研究系统本体——研究树、按玩家记账的进度、科研终端方块、`research_done` 配方条件、完成事件——全部在独立模组 **[研究台] Research Bench（pioneer_research）**（有其独立开发文档）。本模组**不实现研究逻辑**，只把殖民地做成研究的"组织化加速通道"。

- **软依赖**：检测到 pioneer_research 时，市政厅 GUI 挂载研究页（复用其界面代码）；缺失时研究页隐藏，其余功能不受影响
- **colony 通道注册**：通过其 `ResearchApi.registerChannel(...)` 注册"colony 通道"——并行槽位随市政厅等级（1~5 级 → 1/2/2/3/3 项）
- **速度加成（定稿）**：由**研究院**的在岗科研员驱动——每在岗科研员 +15% 研究速度，上限 +60%（可配）
- **发起与付费（定稿）**：市政厅研究页发起，**材料从殖民地仓库扣 + 一次性信用点组织费**（可配）——"组织化研究"：家里囤料，研究不愁；个人在科研终端研 common 研究花自己背包材料，两路**同账本互通**
- **colony_only 研究分支**：数据包里 `channel: "colony_only"` 的研究仅在该通道注册后可见/可研，效果只允许殖民地内部加成（产量/守卫/市民上限），由本模组实现效果
- **红线不变**：锁整包配方的研究全部是 common 通道（科研终端单人可完成）——纯科技玩家与殖民地彻底解耦
- 建筑定义中的 `research_required` 校验的是玩家个人研究记录（读 [研究台] 的进度数据）

## 6. 袭击系统（事件驱动，全模组唯一真实体战斗）

- **威胁值（定稿公式，参照环世界 raid points）**：
  `威胁值 = 建筑总等级 × 系数A × 50%权重 + 缓冲物资价值 × 系数B + 人口 × 系数C + 金库 × 系数D（最低权重）`
  ——建筑只计 50% 权重（避免"多建多挨打"劝退建设）；物资价值**借用市场价目表**（白名单内按基准价折算，一份价格表两处用）。由此自然衍生"财富管理"玩法：多余物资可卖市场变现压威胁，但卖多行情会跌——囤货/变现/抗袭击自行权衡
- **档位**：100 / 250 / 500 / 800 / 1200 → 袭击强度 1~5 档（全可配）；达到档位 → **10 分钟倒计时** + 警报；**胜利后威胁值 -30%**，随财富自然回升
- **方向预警（定稿，参照亿万僵尸）**：倒计时同时预告来袭扇区（如"⚠ 西南方向侦测到袭击集群"），实际刷新点在扇区内随机、受地形影响可偏移——布防有依据但不死板
- **开打条件**：倒计时归零时，**总部 64 格内有在线玩家**才生成袭击波（否则推迟，零成本）；波次数量/强度按威胁档位，从数据包配置敌怪（v1 用原版怪物+装备缩放，v2 可自定义实体）
- **行为目标（定稿）**：波次以总部为目标推进，沿途优先攻击玩家/守卫/市民；**不逐块破坏建筑**——建筑受损是状态标记
- **防御**：玩家亲自防御 + 守卫哨加成；战斗期间**全体市民生成实体参战**（定稿战力：守卫 100%，工人/技工/科研员 25%，均受研究/政策加成），伤亡由**真实战斗结果**结算并写回人口数据——"该死几个死几个"；具体死伤数值参数化进袭击配置（数值待项目主定稿）
- **结算**：阵亡写回人口数据（岗位自动释放）、建筑可能进入"受损"状态（效率 50%，需维修费）、**袭击怪存活超时 5 分钟（可配）自动撤退 = 防守成功**、胜利掉落战利品；总部耐久打空 → 停摆（§3.3）；全公式写回数据
- 实体预算：袭击怪上限（默认 20，可配）+ 市民参战实体按人口规模；战斗仅在总部附近有玩家时发生、随战斗结束实体即清，峰值实体可控

## 7. 经济与商贸（金库 · 市场 · 贸易）

### 7.1 货币与金库

- 殖民地货币**「信用点」（credits，名称可配）**：纯数据余额存于殖民地金库，**无实体物品形态**（从根上杜绝复制卡漏洞）；一切收支走服务端
- **信用点起点（定稿）**：创建殖民地**赠送启动资金**（默认 500，可配）——与任务书投入共同构成前期收入，保证经济闭环从第一小时就能转起来
- 收入来源：市场卖出、任务书/成就奖励（经 API 投入）、袭击胜利战利品折现（可配）；支出：建造/升级的**一次性建设费**（默认开启，可配）、维修费、市场买入、**挂单手续费**（按时长计费）
- **不发工资（定稿）**：殖民地全体为体系内成员，不设持续工资；未来以"政策系统"形式回归（见 §14 v2 设计储备），本期只留经济字段空间
- 金库读写并入 `ColonyApi`，**字段形状与 [活动中心] 的 CurrencyProvider 对齐**（余额/扣款/入账）——将来抽奖货币若选定信用点，写一个薄适配即接，两边都不用改架构

### 7.2 星联市场（服务器级抽象市场）

- 市场是**服务器全局数据**（全服玩家共享同一行情）：datapack 配置 `market/*.json` 定义可交易白名单、基准价、价格下限/上限
- **动态价格**：每 5 分钟按全服近端供需调整——买多涨价、卖多跌价、长期向基准价回归；公式参数全配置化。公开服玩家的集体行为会真实影响行情，形成服级经济玩法（囤货、抛售、搬砖都有意义）
- **贸易站**建筑（datapack 建筑）：解锁市场访问权限；等级决定挂单栏位数与单笔限额
- **挂单撮合（定稿细则）**：玩家在贸易站 GUI 挂买单/卖单（物品+数量+限价可选），经济 tick 期间撮合——**纯数据运算，不需要任何实体在线**，离线挂单照常成交。撮合顺序**价格优先、时间优先**；支持**部分成交**（剩余量继续挂）；不限价的市价单按下一撮合周期市价成交；**卖单从殖民地仓库扣货、买入入库**（市场不碰玩家背包，玩家在建筑 GUI 收取）
- **挂单时长与手续费（定稿）**：挂单自选时长（档位如 1/3/7/14 天，可配），**挂得越久手续费越高**（费率 = 时长档位 × 交易额比例，全参数化），挂单时一次性预扣；挂单期内可随时撤单，物品退回殖民地仓库、**手续费不退**；到期未成交自动下架退回
- **防滥用红线**：单玩家挂单数上限与日交易额上限（可配）；成交价强制夹在 [下限,上限] 区间；全服成交审计日志（时间/玩家/物品/数量/单价）滚动落文件

### 7.3 贸易车队（表现层）

- 大额成交后，若贸易站附近有玩家：生成**商队表现实体**走向贸易站卸货并播放音效；玩家不在附近则跳过表现、纯数据结算
- **移动方式（v1 定稿）**：悬浮直线飞行 + 浮动动画（零寻路成本）；路点系统列 v2
- 商队实体预算 ≤ 4/殖民地，到站即清
- **造型（待项目主定）**：倾向随科研阶段演进——不同科技阶段解锁不同形态（如早期驮兽 → 后期悬浮无人机）与不同效果；v1 先用占位模型

### 7.4 与整包的衔接

- 研究树含**商贸分支**：解锁高价值物品交易权、提升价格档位与挂单栏位
- 任务书对接：首次成交/累计流水里程碑 → 进度事件（复用研究完成的事件机制）

### 7.5 城市间贸易（玩家殖民地互联）

- **贸易协定**：两位总督经贸易站 GUI 签署数据契约——A 出口什么（物品+每小时量）、换回什么（物品或信用点差额结算）、长期有效，**解约需提前 3 个游戏日通知**（给对方调整时间）。契约由服务器强制执行，不存在信任问题，也就没有诈骗空间
- **签约流程（定稿）**：发起方在贸易站生成"协定邀约"（纯数据），对方 **7 天内（可配）在自己的贸易站确认即可，支持离线确认**——不必同时在线
- **执行**：纯数据——经济 tick 期间在两殖民地资源缓冲间转移、信用点轧差；双方离线照常履约
- **路线加成**：每条贸易路线为双方出口商品提供产量加成（路线等级随贸易站等级/商贸研究提升）——鼓励玩家城市专业化分工（一个挖矿、一个种田、一个搞科研，互通有无）
- **城际商队（表现层）**：两端贸易站附近都有玩家时，商队实体在两城之间往返卸货；任一端无人则纯数据结算。同时表现的路线 ≤2 条/殖民地
- **防滥用**：每殖民地协定上限（默认 3 条）；城际交易量并入日交易额上限；全程审计日志；配合"每玩家 1 个殖民地"默认上限，小号走私没有生存空间
- **不做**：自由定价的玩家商店/拍卖行（插件领域）；玩家间单件物品直邮（诈骗与洗货风险，[邮件系统] 同样只做系统邮件）

## 8. 市民模拟与施工表现

### 8.1 市民模拟：跟随玩家模拟距离（核心特色）

- 市民实体**与原版村民同机制**：常驻保存于所在区块；区块被加载且处于服务器模拟距离（simulation-distance）内才 tick。**不发明自定义半径**——玩家把服务器的模拟距离拉大，整座城市所有居民都会模拟（即需求本身）；默认设置下原版机制自动保证"看不见的地方零运算"
- **市民与数据的衔接（定稿）**：人口 +1 → 市民实体在其住宅区块加载时补生成；死亡 → 实体回收、岗位自动释放、聊天栏提示（市民有随机名字，如"市民 张三 因袭击身亡"）。玩家全程不手动"招聘"
- **市民受击规则**：领地内受保护不可被玩家攻击；领地外可被攻击（血量不高）——构成领地防御的动机
- **日程系统**（按 Minecraft 昼夜驱动）：白天在岗位工坊作业（对应工作动作与音效）；正午/傍晚前往**食堂**就餐（同步消耗殖民地食物缓冲的数据）；夜间返回**住宅**。宿舍→工坊→食堂的通勤路径真实可见
- **寻路**：目标点变更时用原版 Navigation **按需**计算一次路径，不做持续寻路；目标区块未加载则原地等待片刻再试
- **规模**：市民总量=人口上限（由住宅决定）；另设可选保险丝 `maxSimulatedCitizens`（默认 -1 不限），公开服需要限制单殖民地模拟规模时可启用
- **岗位与住所绑定在数据层**：datapack 建筑定义声明岗位与床位，"谁住哪、谁在哪上班"是数据记录，实体只是到岗的载体

### 8.2 施工与维修表现（围挡方案）

- 施工期间：建筑 footprint 外圈摆放**施工围挡方块**（专属方块，警示条纹样式），地基常驻；范围内播放位置化建造音效（敲击循环）+ 偶发尘土粒子
- 完成瞬间：围挡与脚手架方块消失，整栋建筑**一次成形** + 完成音效；**不做逐层升起动画**（自定义渲染成本高收益低，明确排除）
- 维修：受损建筑挂"维修中"围挡，支付维修费倒计时后恢复满效；**受损视觉**：受损建筑冒烟粒子 + GUI 红字标注

### 8.3 幸福度与四季供暖（v1）

- **幸福度公式（数值占位可配）**：`幸福度 0~100 = 基础 25 + 供暖达标率×35 + 食物充足率×25 + 住房人均水平×15` → 折算为**人口增速乘数**（约 ×0.5 ~ ×1.5）
- **供暖模型（定稿）**：殖民地级热量池——经 §3.4 扩展资源框架注册**热能 Gauge**（本模组自注册，框架首个内置用户）：锅炉房 + 算力枢纽余热回收**产热**（容量随建筑等级），住宅按季节曲线**耗热**；供暖达标率 = 供给/需求
- **四季联动（并入本模组，不单独立项）**：软依赖 sereneseasons——监听 `SeasonChangedEvent$Standard` 换季事件，切换供暖需求曲线（**12 子季节插值**，冬季 late 为峰值；数值表待项目主）与作物肥沃度对农场产出的影响——冬季作物减产 + 供暖需求上升 = **冬季双重挑战**；未装 sereneseasons 时供暖因子保持中性（不奖不罚），其余功能不受影响
- API 面见《`../四季联动/Seasons研究笔记.md`》（Serene Seasons 10.1.0.3 + glitchcore 前置）

## 12. 风险与约束

- **经济失控是公开服头号风险**：一切水龙头（产出/卖出/奖励/启动资金）与水池（消耗/买入/建设费/手续费/维护）全部参数化在配置；上线前与项目主做一轮"通胀压测"（模拟一周全服产出/消耗曲线）；提供 `/colony economy adjust`（OP）人工修正单个玩家/全服行情；成交审计日志必须可追溯到单笔
- **城际贸易的社会风险**：小号互贸刷资源——默认每玩家 1 殖民地 + 协定/交易量上限 + 审计日志三重兜底；若服主放开多殖民地，需同步下调路线加成
- **领地保护冲突**：整合包保证只装一套保护（本模组内置，不再另装领地模组），上线前做拦截实测（破坏/放置/爆炸/GUI/实体各一条用例）
- **伪空间暂存区**：设计为"只进不出"（除仓库重建后全额返还），不存在刷物品通道；物资转入/返还写入审计日志
- **存档数据增长**：殖民地数据随建筑/缓冲增长，缓冲物品种类设上限并定期压缩；M6.9 实测数据体积
- **数值平衡是持久战**：产出公式全部参数化在 datapack，禁止硬编码；给项目主一份《数值速调手册》（改 JSON→reload 生效）
- 寻路是市民模拟的最大开销：按需一次寻路（非持续）+ 市民总量受住宅上限约束双兜底；M6.5 以 32+ 市民实测寻路帧耗并出报告；公开服可用 simulation-distance 与 `maxSimulatedCitizens` 双旋钮兜底
- 袭击与整包其他刷怪模组的叠加冲突：袭击实体独立队伍标记，避免被任务/事件系统误捕
- 本模组取代 MineColonies：整合包移除 MineColonies/Structurize，任务书与文案不得再引用它们

- 施工/升级材料走殖民地仓库；仓库建成前从玩家背包扣；仓库意外失效时物资进伪空间暂存、重建后全额返还
- 建筑放置范围 = 自购领地区块（免费 3×3 起步，越买越贵，须相邻扩展），不做总部半径限制；领地自带基础保护（对标市面领地模组功能集），保护集成在本模组内
- 建造/升级收一次性信用点建设费；**不发工资**（未来以政策系统回归：点政策 = 效率加成 + 开始发薪）
- 断粮与袭击失败会掉人口；袭击时全体市民实体参战、伤亡按真实战斗结算；具体死伤数值后续定稿（先行参数化占位）
- 取消研究全额退料、进度清零（退还比例可调）——**归属 [研究台] 模组实现**，本模组不涉及
- 挂单可选时长、挂越久手续费越高；可随时撤单（物品退回、手续费不退）
- 商队造型延后定，倾向随科研阶段解锁不同形态与效果（v2）
- **热能作为殖民地资源统合**（环境类资源，经 §3.4 扩展资源框架注册）：供给=锅炉房+算力枢纽余热回收（机房废热集中供热，现实同款方案），需求=住宅供暖（随季节/气候波动）
- **幸福度指数 v1**：供暖达标率/食物供给/住房等级三因子 → 幸福度（0~100）→ 人口增速乘数；供暖因子在四季数据接入后激活，接入前保持中性（不奖不罚）
- **四季联动并入本模组**（不单独立项）：软依赖 sereneseasons——监听 SeasonChangedEvent 切换供暖需求曲线/幸福度供暖因子/作物肥沃度对食物经济的影响；锅炉房与集中供热为本模组建筑；未装 sereneseasons 时全部保持中性（不奖不罚）

- **A1 建筑结构**：多方块结构 + 逻辑核心方块（参照 MineColonies 蓝图模式，建筑机制对标查证：小屋核心+逐级蓝图+维修），施工=倒计时+围挡+**一次成形**（不做逐块建造）；结构蓝图 v1 程序化生成占位；结构方块禁挖，受损=状态标记不逐块破坏；拆除走 GUI（返还材料 50%、建设费不退）

- **C 级记录项**：市民随机名字与死亡提示、领地外市民可被攻击、他人领地边界可见、升级同模型换贴图（占位期不做区分）、受损冒烟粒子
