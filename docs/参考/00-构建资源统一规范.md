# 构建资源统一规范（全项目强制，2026-09-05 总管签发）

> 背景：各项目 Agent 各自下载了 Gradle/JDK/依赖，重复下载浪费且版本漂移。本规范统一构建资源，**执行原则：只对齐到已下载、已验证的资源，不引入新下载**。

## 1. 统一标准（全项目立即对齐）

| 项 | 统一值 | 说明 |
|---|---|---|
| Gradle | **9.1**（腾讯镜像 distributionUrl） | 支持以 Java 25 运行；MDG 2.0.146 已完成项目配置验证 |
| ModDevGradle | **2.0.146** | 星系附属 P0 验证版本；共享缓存已有 |
| JDK 25 | **纯 ASCII 绝对路径 `F:\mctools\jdk25`** | 各项目 `gradle.properties` 设 `org.gradle.java.home=F:/mctools/jdk25`（正斜杠、纯 ASCII） |
| 仓库镜像 | 统一用 §3 模板（BMCLAPI 优先 + NeoForge 官方兜底 + 腾讯/阿里云） | 已验证可用 |
| 缓存 | 统一默认 `~/.gradle`（发行版与构件天然共享） | **禁止**项目级 GRADLE_USER_HOME 隔离、禁止项目内再放 JDK/Gradle |
- ⚠️ **避坑**：Gradle 对 `org.gradle.java.home` 解析出的绝对路径含非 ASCII（中文）字符时拒绝启动 daemon；相对路径在不同项目结构下层级不一致，也不可靠。**结论：路径含非 ASCII 时必须改用纯 ASCII 绝对路径，统一值 `F:/mctools/jdk25`**
